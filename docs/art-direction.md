# الشكل البصري: الشخصيات والحركات

**الحالة:** مقترح للموافقة (يجاوب سؤال ٧ في وثيقة التصميم). معاينة تفاعلية: `docs/preview/roster.html` (افتحها بأي متصفح).

## الاتجاه
- **مسرح برنامج مواهب:** ستارة حمراء، بقعتين ضوء، أرضية خشب داكنة. الخلفية بنفسجي ليلي.
- **شخصيات كرتونية 2D مدوّرة** بألوان واضحة، كل وحدة لها شكل جسم ورأس وعيون وإكسسوار وحركة وقوف خاصة.
- **الفم يتحرك مع صوتك الحقيقي** (من علو المايك) وأنت تغني — هذي اللقطة اللي يبيعها الستريمر.
- **كل شي مرسوم بالكود** (أشكال بسيطة)، بدون ملفات صور. تغيير الشكل = تعديل JSON.

## قواعد ثابتة
1. **الشخصيات شكل فقط** (الوثيقة §10: لا ادفع لتفوز). محمّل الشخصيات **يرفض** أي مفتاح يشبه قوة لعب (`damage`, `hp`, `cooldown`, `charge`, `speed`…).
2. الحركة تأتي من **المقطع** اللي تختاره، مو من الشخصية.
3. كل الألوان والأحجام والتوقيتات في `data/visuals.json`، والشخصيات في `data/characters.json`.
4. كل جملة لها عربي وإنجليزي، والمحمّل يرفض الناقص.

## شكل الحركات (من `visuals.json`)
| الحدث | الشكل |
|---|---|
| خفيفة | ٣ نوتات طايرة بقوس (٤٥٠ms) |
| ثقيلة | موجة صوت هلالية (٦٥٠ms) + اهتزاز أقوى |
| القاضية | ربع حلقة ذهبية مع كل تكرار (٤ = دائرة كاملة)، ثم شعاع كورس ذهبي + اهتزاز قوي |
| مثالية (≥ ٠٫٩) | نوتات ذهبية، انفجار نجوم، كلمة "مثالية ★" |
| نشاز (تحت العتبة) | النوتات تبهت رمادي وتطيح في النص، الشخصية تنحني وتتعرّق، كلمة "نشاز!" |
| كحة/كلام غير معروف | الشخصية تهز راسها، "؟"، وما ينحسب شي |
| تبريد / بدون شحن | "مو جاهزة" / "اشحن أول" |
| K.O. | الخاسر يلف ٣ لفات ويطير برّا المسرح، كونفيتي بألوان الفايز، ثم جملة الفوز والخسارة |
| بداية المباراة | كل شخصية تقول جملة البداية في فقاعة كلام |

## كيف يشتغل في الكود
`Battle` (أحداث) ← `BattlePresenter` (إشارات مرئية بتوقيتها، مختبرة بدون Unity) ← `StageView` في Unity يرسمها.
- `CharacterPuppet.cs` يبني الشخصية بنفس هندسة `drawPuppet` في المعاينة — لو غيّرت واحد غيّر الثاني.
- `Shapes.cs` يولّد الأشكال (دائرة، مستطيل مدوّر، مثلث، نوتة، نجمة، حلقة…).
- `ArabicShaper` يوصل الحروف العربية ويرتبها من اليمين لليسار، لأن نصوص Unity الأساسية ما تسوي هذا.

## إضافة شخصية
1. أضفها في `data/characters.json` (الأشكال المسموحة: الجسم `round/tall/square/pear`، الرأس `round/oval/square`، العيون `dots/big/sleepy/visor`، الإكسسوار `none/mustache/sunglasses/antenna/cat_ears/glasses_bun/chef_hat`، الحركة `bob/sway/bounce/jitter`).
2. `dotnet test VoiceBattle.sln` (يتحقق من الملف).
3. `python3 tools/preview/build.py` لتحديث المعاينة، و `unity/sync.sh` لنقلها لـ Unity.
4. إكسسوار جديد = رسمه في `CharacterPuppet.cs` و `roster.template.html` معاً.

## قرارات تحتاج موافقتك
1. اتجاه "مسرح برنامج مواهب" والشخصيات الست.
2. اللاعب يسار والخصم يمين (مثل أغلب ألعاب القتال)، حتى مع واجهة عربية.
3. الواجهة النهائية (القوائم، اختيار الشخصية) لسا ما انبنت — الحالية فوق المسرح للمطوّر فقط.
