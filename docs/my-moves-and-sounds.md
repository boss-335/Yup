# حركاتي وأصواتي

ميزتين تخلّي اللاعب يجيب مقاطعه بنفسه بدل حزم الملك العام فقط.

## الفرق الأساسي (قاعدة قانونية، لا تُكسر)
| | **حركاتي** (علّم حركتك بالغناء) | **أصواتي** (رفع صوت مثل سناب) |
|---|---|---|
| المحتوى | أي شي تغنيه — حتى أغنية مشهورة | صوت من إنتاجك فقط: جملة، ضحكة، لحن من تأليفك |
| اللي ينحفظ | **منحنى لحن من صوتك فقط**، بدون صوت | الملف الصوتي (بعد القص والتطبيع) + المنحنى |
| وين | جهازك فقط (`persistentDataPath/my_moves.json`) | السيرفر (لاحقاً) — حالياً ملف محلي للتجربة |
| المشاركة | **خاص دائماً — ما ينرفع ولا يتشارك** | خاص / أصدقاء / عام |
| الفحص | الطول يناسب الخانة + تسجيلتين متطابقتين | إقرار حقوق + بصمة صوتية + فلتر محتوى + صلاحية كحركة |

السبب: الوثيقة §5.4 تمنع رفع أغاني غيرك حتى لو خاص. فاللي غنّى عايض أو شاكيرا يقدر يلعب فيها **على جهازه**، لكنها ما تطلع منه. هذا امتداد لفكرة مبارزة الصدى (§4.1) — **يحتاج تأكيد محامي** لأن المنحنى يبقى محفوظ بدل ما ينحذف بعد الجولة.

## حركاتي — كيف تشتغل
1. تختار الخانة (خفيفة ١–٢٫٥ث، ثقيلة ٣–٦ث، قاضية ١–٢ث) وتغني المقطع.
2. تغنيه مرة ثانية بنفس الطريقة. اللعبة تحتاج **تسجيلتين متطابقتين** (≥ ٠٫٦) — الكحة أو أول محاولة غلط ما تخرب الباقي.
3. تكتب اسم (اللاعب يكتبه بنفسه — اللعبة ما فيها أسماء أغاني).
4. تنحفظ وتنحط في الخانة. زر ▶ يدندنها لك من المنحنى (ما فيه تسجيل محفوظ).

الكود: `src/VoiceBattle.Session/Custom/CustomMoves.cs` (`MoveTeacher`, `CustomMoveStore`). الإعدادات: `data/sounds.json` → `teach`.

## أصواتي — المطبّق من §5.4
- **الرفع:** WAV / OGG / MP3، ١–٦ ثوانٍ، ٢ ميجا كحد أقصى. قص يدوي + قص الصمت تلقائياً + تطبيع العلو.
- **إقرار الحقوق إلزامي** بنسخة مرقّمة (`attestation.version`) ويُحفظ مع كل صوت.
- **البصمة الصوتية:** تطابق مع أغنية معروفة = رفض. **فلتر المحتوى:** كلام مسيء/ASR (المزوّد لاحقاً) + فحص العنوان والوسوم: أرقام جوال، إيميلات، روابط، كلمات ممنوعة (القائمة تُعطى من التشغيل، مو بالمستودع).
- **صلاحية كحركة:** لازم المحرّك يلقى فيه لحن (الضجيج يُرفض)، ولازم يناسب خانة وحدة على الأقل (مثلاً ٢٫٧ث ما يناسب لا خفيفة ولا ثقيلة → "قصّه").
- **اقتراح الخانة والصعوبة** تلقائياً من الطول وشكل اللحن.
- **الظهور:** خاص / أصدقاء / عام. **أقل من ١٨ = بدون عام.** حد يومي ١٠.
- **المكتبة:** بحث بالاسم والوسوم (يتجاهل التشكيل والهمزات)، الأحدث، الترند (استخدامات آخر ٧ أيام)، أصوات الأصدقاء.
- **وضع الستريمر:** يخفي الأصوات العامة غير الموثّقة. "موثّق" = راجعه إنسان وما عليه بلاغات.
- **البلاغات والمراجعة:** البلاغ يشيل التوثيق ويدخل طابور المراجعة؛ وكذلك أي صوت عام تجاوز ٥٠٠ استخدام بدون مراجعة.
- **الإشعار والإزالة:** الصوت ينشال فوراً + إشعار للرافع + حق الاعتراض. إزالة مؤكدة = إنذار؛ **٣ إنذارات = إيقاف الرفع.**
- **الحذف:** يختفي فوراً من المكتبة ومن حركات كل اللاعبين؛ الملف والمنحنى ينمسحون نهائياً بعد ٣٠ يوم (§9).
- **إحصائيات الصانع:** عدد الاستخدامات، أعلى دقة، وأوسمة ١٠٠ / ١٠٠٠ / ١٠٠٠٠ مع إشعار.

الكود: `src/VoiceBattle.Sounds/` (يعتمد على `VoiceMatch.Core` فقط — يشتغل في اللعبة أو على سيرفر).

## مقفول عمداً حتى يتحقق شرط
| المقفول | الشرط | الإعداد |
|---|---|---|
| الرفع **العام** | مراجعة محامي للشروط وآلية الإزالة (§11 M6) | `public_uploads_enabled: false` |
| المشاركة مع **الأصدقاء أو العام** | اختيار مزوّد بصمة صوتية + مزوّد فلترة كلام (§12 س٩) | بدونهم: "fingerprint_unavailable" — الخاص يشتغل |

## باقي (قرارات مفتوحة)
1. **الاستضافة:** سيرفر خاص أو Steam Workshop (§12 س٨). المكتبة جاهزة للاثنين؛ ينقص الـ API والتخزين الفعلي.
2. **مزوّد البصمة** (ACRCloud / Audible Magic / …) ومزوّد **ASR** للعربي والإنجليزي.
3. **وكيل DMCA** ومراجعة النظام السعودي قبل فتح العام.
4. واجهة المكتبة في اللعبة (اكتشف، بحث، صفحة الصانع) — الحالي: لوحة المطوّر لتعليم الحركات فقط.
