## التشغيل لأول مرة

1. **Unity Hub ← Add ← Add project from disk** واختر مجلد `VoiceHorror/` (اللي فيه `Assets` و`Packages`). اختر أي نسخة **Unity 6** عندك.
2. أول فتح بيثبّت `com.unity.inputsystem` (المواصفة تطلبه) — إذا سألك «Enable the new input backends?» اختر **Yes** (يعيد تشغيل المحرر). إذا اخترت No، اللعبة تشتغل بنظام الإدخال القديم بدون مشكلة.
3. **macOS:** System Settings ← Privacy & Security ← **Microphone** ← فعّل **Unity** (وUnity Hub). بدونه الميكروفون يعطي صمت.
4. من القائمة: **Tools ← VoiceHorror ← Build All Scenes** (يبني المشاهد الخمسة في `Assets/_Project/Scenes` ويضيفها لـ Build Settings، ويسوي ملفات الإعداد في `Assets/_Project/Config`).

كل مشهد يبدأ بنفس التسلسل: **تنبيه الخصوصية (أول مرة) ← المعايرة (إذا ما فيه معايرة محفوظة) ← تسجيل الأسلحة (إذا يحتاج) ← اللعب.**

**المفاتيح:** WASD حركة · ماوس نظر · Shift ركض (يصدر صوت) · Ctrl/C انحناء · **زر يسار: أدِّ أغنية السلاح** · زر يمين: إلغاء · 1/2/3 تبديل · **V مطوّل: كتم فوري** · E تفاعل · Tab الأشرطة · Esc إيقاف/إعدادات · **F3 شاشة التصحيح**

## خطوات الاختبار اليدوي لكل مرحلة

### M0 — الميكروفون والمعايرة
**Tools ← VoiceHorror ← Build Mic Test (M0)** ثم ▶ Play.
1. يطلع تنبيه الخصوصية ← «فهمت، ابدأ».
2. شاشة المعايرة ← «ابدأ»: (1) اسكت 3 ث (2) اقرأ الجملة بصوتك العادي (3) قل «أنا هنا!» بصوت عالي.
   - المتوقع: «تمت المعايرة» مع ثلاث قيم dB. إذا الغرفة مزعجة يطلع «البيئة مزعجة أو الميكروفون بعيد».
3. أسفل الشاشة مؤشر الصوت فيه 5 مناطق ملونة (رمادي صامت، فيروزي همس، ذهبي كلام، برتقالي عالي، أحمر صراخ) والخط الأحمر = حد الخطر. شاشة التصحيح ظاهرة (F3 للإخفاء).
4. **القبول:**
   - المؤشر يتحرك بسلاسة بدون تذبذب (يطلع بسرعة، ينزل أبطأ).
   - اسكت ← «صامت»، اهمس ← «همس»، تكلم ← «كلام»، ارفع ← «عالي»، اصرخ ← «صراخ». النص فوق المؤشر يقول «يُسمع حتى X م».
   - اضغط V مطوّل ← «مكتوم».
   - أوقف Play وشغّله مرة ثانية ← **ما يطلب معايرة** (انحفظت). Esc ← الإعدادات ← «إعادة المعايرة» تشتغل.
   - افصل الميكروفون أثناء التشغيل ← اللعبة تتوقف مع رسالة وزر «إعادة».

### M1 — نواة التقييم
**أوتوماتيكي (بدون Unity):**
```bash
cd VoiceHorror/dsp-tests && dotnet test
```
المتوقع: `Passed! - Failed: 0, Passed: 43`.

**يدوي:** **Build Score Lab (M1)** ثم Play.
1. «سجّل المرجع» ← دندن لحن 2–4 ث واسكت (يوقف تلقائياً بعد 0.4 ث صمت).
2. «سجّل الأداء» ← أعد نفس اللحن. يطلع المنحنى الأزرق (المرجع) والبرتقالي (أداؤك) بعد المحاذاة + الدرجة وتفاصيلها.
3. **القبول:** نفس اللحن **≥ 70** · لحن مختلف تماماً **≤ 40** · نفس اللحن بطبقة مختلفة (أغلظ/أرفع) **≥ 65**.
4. زر «النوع» يبدّل للعبارة المنطوقة (MFCC).

### M2 — الأسلحة
**Build Weapon Range (M2)** ثم Play.
1. بعد المعايرة تطلع شاشة «مسجّل جدّك»: لكل سلاح (الصدفة، الطار) اختر لحن أو عبارة ← سجّل مرتين.
   - جرّب تسجّل شي قصير جداً / هادي جداً / تسجيلين مختلفين ← لازم **يرفض** مع السبب.
2. في الساحة: 3 دمى على 6 و12 و20 م (ودمية خلف جدار). كل دمية تعرض المسافة وآخر ضرر.
3. اختر الصدفة (1)، صوّب على دمية، **زر يسار**، غنِّ لحن الصدفة، اسكت.
4. **القبول:**
   - الدرجة تطلع وسط الشاشة، والضرر على الدمية يتناسب معها (درجة أعلى = ضرر أعلى وتأثير أكبر).
   - غنِّ شي ثاني ← درجة تحت 35 ← «فشل» و**الضرر 0**.
   - الدمية اللي خلف الجدار ما تنضرب بالشعاع.
   - الطار (2) يضرب كل الدمى القريبة حولك (12 م).
   - خذ الذخيرة المضيئة (E) ← يفتح تسجيل «النَّفَس» (عبارة).

### M3 — الضجيج والمخلوق
**Build Creature Greybox (M3)** ثم Play. (F3 تعرض حالة المخلوق: Idle/Investigate/Hunt/Search.)
1. **القبول:**
   - **الهمس** من بعيد ← المخلوق يكمل تجواله (Idle).
   - **الكلام العادي** وهو ضمن ~10 م (أقل خلف جدار) ← يتحول Investigate ويروح **للمكان اللي تكلمت فيه** — تحرّك بعد ما تتكلم وشوفه يوصل مكانك القديم.
   - كلام مستمر ← Hunt.
   - **الصراخ** ← يجي من أي مكان في الخريطة.
   - **الصمت** ← Search حول آخر مكان ثم Idle بعد ~8 ث.
   - ادخل دولاب (E) ← صوتك ينقص للنص وما يحس فيك وهو جنبك إلا إذا سويت صوت.
   - مقياس الخطر فوق يرتفع مع صوتك وينزل مع الصمت؛ الضباب يحمر والفوانيس تتذبذب.

### M4 — الشريحة العمودية: جزيرة الصمّة
**Build Vertical Slice - Al-Summah Island (M4)** ثم Play. (~10 دقايق)
- المقدمة ← سجّل الصدفة والطار ← تبدأ على المرسى.
- اتبع «الهدف» (أعلى الشاشة) ورسائل مبارك. شغّل الأشرطة (E).
- بيت جدّك مكان آمن: خذ «النَّفَس» من الصندوق تحت الدرج وسجّله هناك.
- السوق: لا تخلي بو درياه يسمعك.
- اللنج: اكسر الصمّة بالطار.
- **القبول:** جلسة كاملة من المعايرة للنهاية بدون أخطاء في Console؛ الموت يعطي «من آخر نقطة»؛ الفوز يعرض النهاية والإحصائيات. ثم 5 لاعبين خارجيين يفهمون الآلية بدون شرح.

## الخصوصية (المواصفة القسم 9)
- كل المعالجة محلية. ما فيه أي اتصال شبكة في الكود.
- نحفظ **الملامح فقط** (`persistentDataPath/VoiceHorror/references/*.json`)، والصوت الخام فقط إذا فعّلت «احفظ تسجيلاتي».
- الإعدادات ← «احذف كل تسجيلاتي». وفي المحرر: **Tools ← VoiceHorror ← Delete Saved Data**.
